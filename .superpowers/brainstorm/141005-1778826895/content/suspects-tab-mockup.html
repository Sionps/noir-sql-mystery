What's shown on each card

  • Photo — your image from public/suspects/{id}.jpg, silhouette fallback if missing
  • Name plate — surname, first initial + file number below photo
  • Full name + role — as the card header
  • Age — single line
  • Physical — height · build · hair · eyes on one line
  • Alibi — italic, slightly dimmed
  • Status stamp — ACCUSED (red) or GUILTY (gold) top-right corner

The sidebar keeps its small 2-col card grid (for quick reference). The Suspects tab shows the full dossier view.
